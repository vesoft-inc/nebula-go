# 结果处理

本文档详细介绍如何处理查询返回的结果集。

## 结果集结构

```
Result (结果集)
├── Columns()     -> []string       // 列名列表
├── ColumnTypes() -> []ColumnType   // 列类型
├── RowSize()     -> int            // 行数
├── HasNext()     -> bool           // 是否有更多行
├── Next()        -> Row            // 获取下一行
├── Scan(...any)  -> error          // 扫描到变量
└── Summary()     -> Summary        // 执行摘要
```

## 遍历结果集

### 基本遍历

```go
resp, err := client.Execute("MATCH (n:player) RETURN n.name, n.age LIMIT 5")

// 检查是否有数据
fmt.Println("Columns:", resp.Columns())

for resp.HasNext() {
    row, err := resp.Next()
    if err != nil {
        panic(err)
    }
    
    // 获取所有值
    values := row.Values()
    for _, v := range values {
        fmt.Printf("%s ", v.String())
    }
    fmt.Println()
}
```

### 按索引获取值

```go
row, _ := resp.Next()

// 按列索引获取（从 0 开始）
name, err := row.GetValueByIndex(0)
age, err := row.GetValueByIndex(1)
```

### 按名称获取值

```go
row, _ := resp.Next()

// 按列名获取
name, err := row.GetValueByName("n.name")
age, err := row.GetValueByName("n.age")
```

## 使用 Scan 扫描到结构体

Scan 是最高效的结果获取方式，直接将列映射到 Go 结构体。

### 基本用法

```go
var (
    name nebula.NullString
    age  nebula.NullInt64
)

for resp.HasNext() {
    if err := resp.Scan(&name, &age); err != nil {
        panic(err)
    }
    
    if name.Valid {
        fmt.Printf("Name: %s, Age: %d\n", name.Data, age.Data)
    }
}
```

### 使用结构体（struct 定义在 for 循环内部）

```go
type Player struct {
    ID   nebula.NullInt64
    Name nebula.NullString
    Age  nebula.NullInt
}

for resp.HasNext() {
    // 每次循环创建新的 struct 实例
    var p Player
    if err := resp.Scan(&p.ID, &p.Name, &p.Age); err != nil {
        panic(err)
    }
    
    // 每次循环的 p 是独立的对象
    if p.ID.Valid && p.Name.Valid {
        fmt.Printf("ID: %d, Name: %s, Age: %d\n", 
            p.ID.Data, p.Name.Data, p.Age.Data)
    }
}
```

### 使用结构体（struct 定义在 for 循环外部）

```go
type Player struct {
    ID   nebula.NullInt64
    Name nebula.NullString
    Age  nebula.NullInt
}

// 在 for 循环外部定义，只创建一次
var p Player

for resp.HasNext() {
    // 复用同一个 struct 实例，每次 Scan 会覆盖其字段值
    if err := resp.Scan(&p.ID, &p.Name, &p.Age); err != nil {
        panic(err)
    }
    
    // 注意：如果在循环内异步使用 p（如 goroutine），
    // 必须在循环内定义，否则值会被后续覆盖
    if p.ID.Valid && p.Name.Valid {
        fmt.Printf("ID: %d, Name: %s, Age: %d\n", 
            p.ID.Data, p.Name.Data, p.Age.Data)
    }
}
```

### 两种定义方式的区别

| 方式 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| for 内定义 | 每次循环独立，安全 | 每次循环分配内存 | 推荐，代码更安全 |
| for 外定义 | 减少内存分配 | 需注意值被覆盖 | 循环内无异步操作时使用 |

```go
// ❌ 错误示例：for 外定义 + 异步使用
var p Player
for resp.HasNext() {
    resp.Scan(&p.ID, &p.Name, &p.Age)
    // 错误：goroutine 捕获的是同一个地址，后续值被覆盖
    go func() {
        fmt.Println(p.Name)  // 可能输出错误的值
    }()
}

// ✅ 正确示例：for 内定义
for resp.HasNext() {
    var p Player
    resp.Scan(&p.ID, &p.Name, &p.Age)
    // 正确：每次循环创建新实例
    go func() {
        fmt.Println(p.Name)  // 值是正确的
    }()
}
```

### 支持的类型

| Go 类型 | Nebula 类型 |
|---------|------------|
| `*int` | INT8, INT16, INT32, INT64 |
| `*uint` | UINT8, UINT16, UINT32, UINT64 |
| `*float32` | FLOAT |
| `*float64` | FLOAT, DOUBLE |
| `*string` | STRING |
| `*bool` | BOOL |
| `*nebula.NullXXX` | 对应类型，支持空值 |

## 空值处理

NebulaGraph 的空值使用 `NullXXX` 类型包装：

```go
// NullString - 字符串，可能为空
var name nebula.NullString
if err := resp.Scan(&name); err != nil {
    panic(err)
}
if name.Valid {
    fmt.Println("Name:", name.Data)
} else {
    fmt.Println("Name is NULL")
}

// 其他空值类型
var (
    id        nebula.NullInt64
    score     nebula.NullDouble
    createdAt nebula.NullDate
    isActive  nebula.NullBool
)
```

## 获取执行摘要

```go
summary := resp.Summary()
if summary == nil {
    return
}

// 时间统计（微秒）
fmt.Printf("Parse time:    %d μs\n", summary.ParseTimeUs())
fmt.Printf("Build time:    %d μs\n", summary.BuildTimeUs())
fmt.Printf("Optimize time: %d μs\n", summary.OptimizeTimeUs())
fmt.Printf("Execute time:  %d μs\n", summary.TotalServerTimeUs())

// 查询统计
stats := summary.QueryStats()
if stats != nil {
    fmt.Printf("Affected nodes: %d\n", stats.NumAffectedNodes())
    fmt.Printf("Affected edges: %d\n", stats.NumAffectedEdges())
}

// 警告数量
fmt.Printf("Warnings: %d\n", summary.NumWarnings())
```

## 最佳实践

1. **优先使用 Scan** - 比 GetValueByIndex/Name 性能更好
2. **使用 NullXXX 处理空值** - 避免类型不匹配错误
3. **检查 Valid 字段** - 访问数据前先检查是否为空
4. **及时遍历** - Result 需要被完全遍历或显式关闭
