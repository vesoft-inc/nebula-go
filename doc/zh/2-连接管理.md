# 连接管理

本文档详细介绍如何使用 SDK 进行连接管理。

## 创建单个客户端

### 基本用法

```go
client, err := nebula.NewNebulaClient(
    "127.0.0.1:10025",  // 地址（可多个，逗号分隔）
    "root",              // 用户名
    "nebula",            // 密码
)
if err != nil {
    // 处理错误
}
defer client.Close()
```

### 支持多个地址（故障转移）

```go
// 多个地址用逗号分隔，SDK 会自动尝试连接
addresses := "192.168.1.1:10025,192.168.1.2:10025,192.168.1.3:10025"
client, err := nebula.NewNebulaClient(addresses, "root", "nebula")
```

## 客户端配置选项

```go
// 连接超时（默认 3 秒）
nebula.WithClientConnectTimeout(5 * time.Second)

// 请求超时（默认 60 秒）
nebula.WithClientRequestTimeout(30 * time.Second)

// 自定义日志
nebula.WithClientLogger(customLogger)

// 自定义认证信息
nebula.WithClientAuthInfo(map[string]string{
    "password": "nebula",
    "tenant": "tenant_name",
})
```

## 检查连接状态

```go
// Ping 检查连接是否有效
if err := client.Ping(); err != nil {
    fmt.Println("连接无效:", err)
}

// 使用 context 的 Ping
ctx, cancel := context.WithTimeout(context.Background(), 2*time.Second)
defer cancel()
if err := client.PingContext(ctx); err != nil {
    fmt.Println("连接无效:", err)
}
```

## 获取连接信息

```go
// 获取 Session ID
sessionId, err := client.GetSessionId()

// 获取服务器版本
version, err := client.GetVersion()
```

## 关闭连接

```go
// 关闭客户端连接
if err := client.Close(); err != nil {
    // 处理错误
}
```

## 完整示例

```go
package main

import (
    "context"
    "fmt"
    "time"
    
    nebula "github.com/vesoft-inc/nebula-go/v5"
)

func main() {
    // 创建带配置的客户端
    client, err := nebula.NewNebulaClient(
        "127.0.0.1:10025",
        "root",
        "nebula",
        nebula.WithClientConnectTimeout(5*time.Second),
        nebula.WithClientRequestTimeout(30*time.Second),
    )
    if err != nil {
        panic(err)
    }
    defer client.Close()

    // 检查连接
    if err := client.Ping(); err != nil {
        panic(err)
    }

    // 获取版本信息
    version, _ := client.GetVersion()
    fmt.Printf("Connected to NebulaGraph %s\n", version)

    // 执行查询
    resp, err := client.Execute("SHOW HOSTS")
    if err != nil {
        panic(err)
    }
    fmt.Printf("Columns: %v\n", resp.Columns())
}
```

## 最佳实践

1. **总是使用 defer Close()** - 确保程序退出时释放连接资源
2. **设置合理的超时** - 根据业务需求设置连接和请求超时
3. **处理连接失败** - 使用 Ping 检查连接健康状态
4. **多地址故障转移** - 生产环境建议配置多个地址
