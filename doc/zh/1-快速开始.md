# 快速开始

本文档帮助你快速上手 NebulaGraph Go SDK。

## 安装

```bash
go get github.com/vesoft-inc/nebula-go/v5@v5.2.0
```

## 基本使用示例

```go
package main

import (
    "fmt"
    nebula "github.com/vesoft-inc/nebula-go/v5"
)

const (
    address  = "127.0.0.1:10025"
    username = "root"
    password = "nebula"
)

func main() {
    // 创建客户端
    client, err := nebula.NewNebulaClient(address, username, password)
    if err != nil {
        panic(err)
    }
    defer client.Close()

    // 执行查询
    resp, err := client.Execute("RETURN 1 + 1 AS result")
    if err != nil {
        panic(err)
    }

    // 处理结果
    for resp.HasNext() {
        row, err := resp.Next()
        if err != nil {
            panic(err)
        }
        value, _ := row.GetValueByIndex(0)
        fmt.Println(value)
    }
}
```

## 使用连接池

```go
package main

import (
    "fmt"
    "time"
    nebula "github.com/vesoft-inc/nebula-go/v5"
)

const (
    address  = "127.0.0.1:10025"
    username = "root"
    password = "nebula"
)

func main() {
    // 创建连接池
    pool, err := nebula.NewNebulaPool(
        address, username, password,
        nebula.WithPoolConnectTime(10*time.Second),
        nebula.WithPoolRequestTimeout(10*time.Second),
        nebula.WithPoolMaxOpenConns(100),
    )
    if err != nil {
        panic(err)
    }
    defer pool.Close()

    // 获取客户端
    client, err := pool.GetClient()
    if err != nil {
        panic(err)
    }
    defer pool.PutClient(client)

    // 执行查询
    resp, err := client.Execute("RETURN 1 + 1 AS result")
    if err != nil {
        panic(err)
    }

    for resp.HasNext() {
        row, _ := resp.Next()
        value, _ := row.GetValueByIndex(0)
        fmt.Println(value)
    }
}
```

## 核心概念

| 概念 | 说明 |
|------|------|
| `Client` | 单个客户端连接，用于执行查询 |
| `Pool` | 连接池，管理多个客户端连接 |
| `Result` | 查询结果集，包含数据和摘要 |
| `Row` | 结果集中的一行数据 |
| `Summary` | 查询执行统计信息 |
